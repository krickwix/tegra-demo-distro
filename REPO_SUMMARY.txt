🚀 NEXT STEPS
═══════════════════════════════════════════════════════════════════════════════

   1. Initialize Repository Metadata
      $ ./setup-yum-repo.sh

      This will:
      - Install createrepo_c (requires sudo)
      - Generate repository metadata for all 8 directories
      - Create client configuration files

   2. Start Repository Server

      Option A - Quick Test Server:
      $ ./start-repo-server.sh
      (Serves on http://localhost:8080)

      Option B - Production Nginx:
      $ sudo cp repo-configs/nginx-tegra-repo.conf /etc/nginx/sites-available/
      $ sudo ln -s /etc/nginx/sites-available/nginx-tegra-repo.conf \
                   /etc/nginx/sites-enabled/
      $ sudo nginx -t && sudo systemctl reload nginx

   3. Configure Client Devices

      Copy appropriate repo file to Jetson:
      $ scp device-specific-repos/jetson-agx-xavier.repo nvidia@jetson:/tmp/

      On Jetson device:
      $ sudo cp /tmp/jetson-agx-xavier.repo /etc/yum.repos.d/
      $ sudo nano /etc/yum.repos.d/jetson-agx-xavier.repo
        (Replace YOUR_SERVER_IP with actual IP)
      $ sudo dnf clean all && sudo dnf makecache
      $ sudo dnf repolist

💡 TIPS
═══════════════════════════════════════════════════════════════════════════════

   • Device-specific repos use priority=5 (higher priority)
   • Architecture repos use priority=10 (lower priority)
   • This ensures device packages override generic ones
   
   • GPG checking is disabled by default (gpgcheck=0)
   • Enable GPG signing in production for security
   
   • Repository metadata updates automatically with ./update-repo.sh
   • Run after each package build to keep repo current

📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

   If clients can't connect:
   1. Check firewall: sudo ufw allow 80/tcp
   2. Test locally: curl http://localhost/tegra-repo/noarch/repodata/repomd.xml
   3. Check web server: sudo systemctl status nginx
   
   If packages not found:
   1. Update metadata: ./update-repo.sh
   2. Clear client cache: sudo dnf clean all && sudo dnf makecache
   
   If metadata errors:
   1. Regenerate: rm -rf /path/to/repo/repodata && createrepo_c /path/to/repo
   2. Or use: ./setup-yum-repo.sh (rebuilds all)
